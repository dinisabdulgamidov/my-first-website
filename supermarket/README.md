# Мой Маркет — онлайн-супермаркет

Демонстрационный frontend интернет-магазина продуктов для российского рынка.

## Уже работает
- Адаптивная главная страница и каталог
- Фильтрация по категориям и поиск
- Добавление товаров в корзину
- Изменение количества и пересчёт суммы

## Запуск
Откройте `index.html` в браузере. Для публикации можно использовать GitHub Pages.

## Ограничения прототипа
Это только frontend. Сервер, база данных, аккаунты, реальное оформление заказа, онлайн-оплата, складские остатки и интеграция доставки ещё не подключены. Все товары и цены демонстрационные.

## Дальнейшая разработка
1. Определить город и зону доставки.
2. Подключить backend и PostgreSQL.
3. Реализовать аккаунты и админ-панель.
4. Добавить оформление заказа и управление статусами.
5. Подключить доступного в России платёжного провайдера после проверки требований.
6. Интегрировать собственную или внешнюю доставку.
